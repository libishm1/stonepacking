🚧 StonePacking-3JS
A Three.js Web App for Procedural 3D Packing of Randomly Scaled Dodecahedrons

This project ports my original StonePacking-3D (Python) logic into a browser-friendly TypeScript + Three.js implementation, using instanced rendering, a spatial grid, and strict Power-of-Ten coding principles to guarantee clarity and performance.

This README is also a Cursor / Codex instruction anchor.
Any code generated must follow the constraints defined below.

🎯 Project Goal

Create a lightweight web tool that:

Packs N randomly-scaled dodecahedrons inside a 3D container box

Avoids overlaps using bounding spheres + a spatial grid

Runs efficiently in the browser

Renders with Three.js InstancedMesh

Provides UI controls for count, scale range, container size

Uses deterministic, predictable architecture suitable for expanding later

Allows exporting or screenshotting scenes in future versions

This project is intended to be modular, auditable, and simple enough to extend.

🧠 Core Algorithm Specification (Cursor must follow exactly)
1. Object Definition

Each packed item is a dodecahedron with:

Uniform scale (scale)

Bounding sphere (radius = BASE_RADIUS * scale)

Quaternion rotation

Position inside container

2. Placement Strategy

For each object:

Generate random rotation + scale

Randomly sample a position inside container

Check container boundary constraints

Check collisions using neighbor cells in spatial grid

If valid → place

If invalid → retry (up to MAX_ATTEMPTS)

Fail gracefully if placement not possible

3. Collision Detection

Must use:

Bounding spheres (no mesh-mesh intersection)

Spatial grid acceleration (avoid O(n²))

Neighbor cell lookup only

4. Power-of-Ten Software Principles

Enforce:

No deep nesting (>2 levels)

Small, pure functions

Fail-fast returns

No recursion

No clever magical shortcuts

All state transitions explicit

All loops bounded

Predictable behavior

Maintain clarity even at the cost of performance

🎨 Rendering Specification (Three.js)
1. Use InstancedMesh

One dodecahedron geometry → reused for all objects:

const mesh = new THREE.InstancedMesh(
    dodecaGeometry,
    material,
    count
);

2. Compose instance transforms:
matrix.compose(position, quaternion, new THREE.Vector3(scale, scale, scale));
mesh.setMatrixAt(i, matrix);

3. A wireframe container box must be visible

Useful for debugging the packing.

4. Use r160+ Three.js features

No deprecated APIs like Geometry.

⚙️ Spatial Grid Rules

To avoid quadratic collision checks:

cellSize ≈ average object radius * 2

Each cell stores references to objects inside it

Collision test inspects only the current cell + 26 neighbors

Grid lives in grid.ts

Grid responsibilities:

Convert position → cell index

Insert object into grid

Retrieve neighbors

Perform safe bounds checks

🧱 Container Rules

Container is axis-aligned:

{
  width: number;
  height: number;
  depth: number;
}


Boundary check must be conservative using radius.

🧬 Randomness

For reproducibility, internally we may switch to a seeded RNG.
Until then: Math.random() is fine.
